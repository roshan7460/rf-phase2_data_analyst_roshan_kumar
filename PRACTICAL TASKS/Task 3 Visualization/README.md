

##  Project Overview

This repository contains the **Phase 2 practical task** of my **Data Analyst Internship at Rasheed Foundation**.  
The project focuses on analyzing a global sales dataset and building an **interactive Power BI dashboard** to extract meaningful business insights.

---



##  Tools & Technologies Used

- Microsoft Power BI  
- Microsoft Excel  
- Data Cleaning & Transformation  
- Data Visualization  
- Business Intelligence Concepts  

---

##  Dashboard Highlights

The Power BI dashboard provides insights on:

- ✔ Total Sales & Profit Overview  
- ✔ Region-wise Sales Performance  
- ✔ Category & Sub-category Analysis  
- ✔ Customer Segment Analysis  
- ✔ Time-based Sales Trends  
- ✔ Interactive Filters and Slicers  

---

##  Key Insights

- Identified high-performing regions and products  
- Analyzed profit contribution across categories  
- Observed sales trends over time  
- Highlighted underperforming segments for improvement
