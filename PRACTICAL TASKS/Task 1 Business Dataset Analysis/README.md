# 📊 Superstore Sales Data Analysis

## 📌 Project Overview
This project focuses on analyzing a retail superstore dataset to extract meaningful business insights using Python and Pandas.

## 📂 Dataset
- Source: Kaggle
- Name: Superstore Sales Dataset
- Records include sales, profit, customer, product, and regional information.

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 🧹 Data Cleaning Process
- Checked for missing values (no missing values found)
- Checked for duplicate records (no duplicates found)
- Converted date columns to datetime format

## ❓ Business Questions Answered
1. Which region generates the highest sales?
2. Which product category is most profitable?
3. What is the yearly sales trend?
4. Who are the top 5 customers by sales?
5. Which market contributes the highest profit?

## 📈 Visualizations
- Sales by Region (Bar Chart)
- Profit by Category (Bar Chart)
- Year-wise Sales Trend (Line Chart)
- Top Customers by Sales (Bar Chart)

## 📊 Key Insights
- Certain regions contribute significantly higher sales
- One product category dominates overall profit
- Sales trends indicate business growth patterns
- A small number of customers drive large revenue

## 📁 Output
- Cleaned dataset saved for further analysis

## 🚀 Conclusion
This analysis demonstrates how business data can be cleaned, analyzed, and transformed into actionable insights using Python.
